# 物流可视技术知识库

本知识库面向首次接触物流可视项目的研发、测试和运维人员。内容以当前检出的真实代码为主要证据，覆盖 `iscm-trace-subscribe`、`iscm-trace-schedule`、`iscm-trace-sf`、`iscm-trace-sf-data-mix`、`iscm-trace-notify-platform`、`iscm-trace-admin` 和 `iscm-trace-admin-web`。

## 阅读顺序

1. 先阅读 `00-新人导航`，理解服务边界、核心对象和联调入口。
2. 再按编号阅读 `01-核心业务链路`，串起订阅、调度、采集、清洗、融合、通知和结束链路。
3. 遇到消息重复、数据不一致、任务失败等问题时，阅读 `02-可靠性与平台能力`。
4. 需要操作后台或排障时，阅读 `03-运营后台与问题排查`。
5. 负责码头、海关、快递、船计划或定制客户时，阅读 `04-专项业务链路`。

## 证据标记

- **代码已确认**：可在当前检出源码中定位到类、方法或配置。
- **设计文档说明**：来源于仓库内设计文档，正式使用前仍需和当前实现核对。
- **合理推断**：由多处代码关系推导，但缺少单一直接证据。
- **当前代码无法确认**：相关消费者、部署配置、线上参数或外部服务不在本次仓库范围。

## 文档质量约束

每篇业务文档均应说明背景、代码位置、调用流程、实现原理、方案原因、技术细节、异常边界和优化方向。除简单字典类主题外，正文保持足够的信息密度，不使用三五行概述、重复段落或与项目无关的通用八股文。
