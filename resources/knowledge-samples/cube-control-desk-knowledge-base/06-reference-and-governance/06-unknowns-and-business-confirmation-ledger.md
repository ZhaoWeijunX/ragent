# 未知项与业务确认台账

> 最后核验：2026-08-26。未知不等于缺陷；在得到证据前不得编造。

| 未知项 | 代码能证明什么 | 需要何种确认 |
| --- | --- | --- |
| 生产启用的租户/船司/通道 | 读取逻辑、默认值和策略映射 | 脱敏生产配置快照与运维确认 |
| Job cron、executor、开关 | handler、参数解析、扫描逻辑 | 调度平台配置和最近运行记录 |
| 外部 RPA/官网能力 | 请求/回执契约与错误处理 | 沙箱/生产契约测试和版本 |
| 前端实际使用字段 | 后端 Controller/DTO | 前端分支与接口调用证据 |
| 产品状态文案 | 状态 code、迁移条件 | 产品规则与用户操作说明 |
| 生产 schema/索引一致性 | 仓库 SQL 和实体 | 数据库 migration 记录/只读检查 |
| 日志/告警保留和阈值 | 日志点与统计 Job | 可观测平台配置 |
| 第三方数据质量/SLA | client、超时、重试代码 | 合同/SLA 与运行指标 |
| 历史脚本是否仍启用 | resources 中脚本和调用器 | 配置 key、版本与最近执行审计 |
| api-test 全链覆盖 | 场景文件和 README | 新鲜执行报告与未覆盖清单 |

确认结果必须附日期、环境、来源和适用范围；不能把某一租户观察推广为全局规则。敏感配置只记录结构和结论。

面试追问：如何在信息不足时做架构判断、如何区分风险与未知、如何设计可证伪的验证。
